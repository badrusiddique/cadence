# E2E UI review — Cadence 1.0

**Roles:** PM · developer · end user  
**Surface:** Fixture preview `http://127.0.0.1:43127`  
**Evidence:** `/opt/cursor/artifacts/e2e-1x/`

## What adds value (keep)

| Area | Why users care |
|---|---|
| Dashboard practice rings + WoW + charts | Instant coaching signal |
| Date range + Current/All + harness filters | Credible scoping |
| Timeline day view + turn drill-down | Debug a session without leaving Cadence |
| Output multi-mode charts | Answers “where did the LOC go?” |
| Burndown with estimate disclaimer | Budget awareness without fake billing |
| Patterns / Curiosity / Flow / Context | Measure depth for agentic habits |
| Anti-Patterns + Rules coverage | Actionable improve loop |
| Rule Studio Save → Approve | Trust-correct adaptation |
| Signal Lab evaluate + reference | Easy to adopt custom rules |
| Skill Finder community | Offline discovery |
| Share snapshot | Weekly ritual / team share |
| Theme toggle + mobile load | Usable outside default dark VS Code |

## Lower value (keep, don’t lead with)

| Area | Note |
|---|---|
| Achievements XP/tier | Light gamification — fine as Level Up garnish |
| Hub | Useful when prompts cite `#issue` / PRs; otherwise quiet |
| Lifecycle | Depends on `workType` tagging quality |

## Issues found → fixed in 1.0.0

| Severity | Issue | Fix |
|---|---|---|
| Medium | Achievements “NameEARNED” jammed | Flex row + gap on badge list |
| Medium | Moments missing when/where time | Show timestamp on each moment |
| Medium | Share Copy gave no feedback | “Copied” status after click |
| Medium | Lifecycle no interpretation | One-line dominant-phase insight |
| Low | Theme control a11y | Explicit `aria-label` |
| Low | Marketplace icon looked generic | New Cadence **C + pulse** mark (128/256) |
| Low | Activity bar still reticle | SVG aligned to C + rhythm bars |
| — | Automated walk | 19/19 pages, 0 JS errors, charts paint |

## Verdict

Cadence 1.0 is **ready to ship as a local coaching product**: workflows that Observe → Measure → Improve → Adapt work end-to-end on fixtures. Lead marketing with Dashboard, Output, Anti-Patterns, and Lab/Studio — not Achievements.
